# My Portfolio

Personal portfolio website showcasing my experience and projects as a Frontend Developer.

## 🚀 Tech Stack

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS** for styling
- **Supabase** for backend and database
- **TanStack Query** for data fetching

## 📂 Structure

```
src/
├── app/          # App configuration
├── features/     # Experience cards, carousel
├── shared/       # UI components, API, types
└── widgets/      # Main content, sidebar
```
